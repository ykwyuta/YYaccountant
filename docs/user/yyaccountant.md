# YYaccountantの使い方

## はじめに

1. パスワードを作ります。`yyaccountant --generate-password あなたの名前` を実行すると、`yya_` で始まるパスワードが1回だけ表示されます（閲覧だけの人には `--read-only` を付けます）。
2. `yyaccountant --web books.sqlite3` を実行し、`http://127.0.0.1:8750/` を開いてログインします。ファイルがなければ新しく作られます。
3. 「新規帳簿」で帳簿を作ります。1つのSQLiteファイルに複数の帳簿を入れられます。

| 種類 | 向いている使い方 | 科目の特徴 |
|---|---|---|
| 家計 | 生活費・貯蓄・ローンの管理 | 食費・外食費・日用品・特別支出など、生活の目的別 |
| 個人事業主 | 事業の記帳・青色申告の準備 | 青色申告決算書の経費科目、事業主貸・事業主借・元入金 |

副業や個人事業をしている人は、事業用と家計用の帳簿を分けて作り、事業から生活費に回したお金を事業の帳簿では「事業主貸」、家計の帳簿では収入または振替として記録すると、両方が正しく集計されます。

**記帳を始めるとき**は、仕訳帳で「開始時の残高」を1件入れます。例: 普通預金 1,450,000 ／ 現金 32,000 を借方、開始残高（家計）または元入金（事業）を貸方に、合計を一致させます。ローンなど残高のある債務は債権・債務画面で登録し、発生の仕訳を作る相手科目に「開始残高」を選ぶと、残高と返済予定が同時に入ります。

## Windowsのネイティブ画面

Windowsでは、ブラウザーやパスワードなしで使える `yyaccountantw.exe` もあります。`yyaccountantw books.sqlite3` で開くか、ファイルを指定せずに起動すると `%LOCALAPPDATA%\YYaccountant\books.sqlite3` を使います。帳簿がまだなければ「新しい帳簿」のフォームが開きます。「ファイル」メニューから、別のデータベースを開く・読み取り専用で開く・新しいデータベースやデモを作る・バックアップ・仕訳CSVの保存ができます。

| 画面 | できること |
|---|---|
| かんたん入力 | 支出・収入・振替の登録。右側の「科目を探す」に内容（例: ガソリン）を入れると候補が出て、選ぶと科目の使い方と似た科目との使い分けを表示します。個人事業主の支出では事業割合（%）も入れられます。 |
| 仕訳帳 | 期間・検索語（摘要・科目・取引先・金額）での絞り込み、選んだ仕訳の明細、取消と取消の解除、「修正」「複写して入力」。 |
| 仕訳入力 | 複数行の仕訳。科目と借方または貸方の金額を入れて「行を追加」（Enterでも追加）。一覧の行を選ぶと入力欄に戻って直せます。下に借方・貸方の合計と差額を表示し、一致しないと保存できません。 |
| 帳票 | 試算表・損益計算書・貸借対照表・総勘定元帳。開始日を空にした試算表は期首残高なしの累計です。 |

- Ctrl+1〜4（またはCtrl+Tab）で画面を切り替え、F5で最新の内容を読み込みます。かんたん入力ではEnterで登録します。
- 同じファイルをWeb UIやAI（MCP）が更新すると、約1秒で自動的に読み込みます。先に他で更新された後に保存すると上書きせず、最新を読み込んで入力内容を残したまま知らせるので、確認してからもう一度保存します。
- 操作者は「Windowsのユーザー名（Windows）」として変更履歴に残ります。
- 債権・債務、予算、計画、原価管理、統計・予測、勘定科目・取引先の編集はWeb UIかMCPで行います。同じファイルを同時に開いて構いません。

## かんたん入力

「支出」「収入」「振替」を選び、日付・金額・科目・支払方法を入れます。金額は全角数字や「1,980円」のような書き方でも構いません。

- **科目を探す**: 「ガソリン」「打合せのコーヒー」「住民税」など内容を入れると候補が表示されます。科目を選ぶと右側に**使い分けの説明**と、似た科目との比較表が出ます。比較表の科目名を押すとその科目に切り替わります。
- **クレジットカード**: 買った日に「支出」、支払方法「クレジットカード」で記録し、引落し日は「振替」で「移動先: クレジットカード、移動元: 普通預金」と記録します。引落しを支出にすると二重計上になります。
- **振替**: ATM引出し、口座間の移動、電子マネーのチャージ、投資信託の購入、ローン元金の返済のように、収入でも支出でもない移動です。
- **事業割合**（個人事業主）: 自宅兼事務所の家賃・光熱費・通信費は、事業で使う割合を%で入れると、事業分をその科目に、残りを事業主貸に自動で分けます（端数は帳簿の端数処理に従います）。

## 仕訳帳

すべての取引は借方と貸方の合計が一致する仕訳です。「仕訳を追加」で行を増やし、複数の科目に分かれる取引（給与の額面と天引き、返済の元金と利息など）を1件で記録できます。入力中は借方・貸方の合計と差額を表示し、一致しないと保存できません。

行をクリックすると編集できます。間違えた仕訳は「取り消す」で取消にします（削除はせず、監査のために残ります。「取消を解除」で戻せます）。計画・回収返済・減価償却から自動で作った仕訳は、取消すと再び計上できます。

## 勘定科目・取引先

- **勘定科目**: 科目の追加・名称変更・説明の編集・使用停止ができます。使用中の科目は削除できないため、使わなくなった科目は「使用停止」にします。「役割」は自動計上に使う科目（利息、事業主貸、減価償却費など）を表します。「支払手段」を付けた科目がかんたん入力の支払方法に出ます。
- **使い分けガイド**: 迷いやすい科目の組み合わせと例の一覧です。検索欄に内容を入れると関係する説明だけを表示します。同じ内容は[勘定科目の選び方](accounts.md)にもまとめています。
- **取引先**: 仕訳・債権債務・計画に付けて検索や集計に使います。

## 債権・債務

貸したお金・売掛金（債権）と、ローン・借入金・買掛金（債務）を登録します。

- **返済方法**: 一括、元利均等（毎回の支払額が一定）、元金均等（元本の返済額が一定）。年利と回数から返済予定表を計算します。月利は年利÷12、利息は残高×月利を帳簿の端数処理で丸め、最終回で元本の端数を調整します。一括の利息は日割り（年365日）です。
- **発生の仕訳**: 新規登録時に相手科目を選ぶと、元本の仕訳を作ります（例: 友人に貸した→普通預金、ローンで車を購入→特別支出）。
- **回収・返済**: 次回分の元本と利息が入力済みの画面で、入出金の口座を選んで計上します。元本は債権債務の科目、利息は受取利息・支払利息に分かれます。残高が0になると完了になります。
- **延滞とエイジング**: 基準日までに返っているはずの元本との差を延滞額とし、最も古い未済の期日からの日数で「期日内／1〜30日／31〜90日／91日以上」に分類します。

## 予算

年度（期首月は帳簿設定）ごとに、収益・費用の科目別・月別の予算を作ります。「全月」欄に入れると12か月に同じ額が入ります。予算画面では年間の予算・実績・差異・達成率と、月別の実績（上段）・予算（下段）を表示し、予算のない科目に実績があれば「予算なし」と表示します。ホームでは今月の予算消化をメーターで表示します。

## 計画

家賃・保険料・積立のような定期取引（毎週・毎月・毎年、間隔指定、終了日）と、冷蔵庫の買い替えのような1回の予定支出を登録します。計画は**計上するまで帳簿に影響しません**。予定日を過ぎると「計上待ち」に出るので、金額や日付を実際に合わせて「計上」します。同じ予定日は二重に計上できません。月末日（31日）を初回にした毎月の計画は、30日までの月は月末に置き換えます。

## 原価管理

複数の原材料と設備を使う製品の原価を計算します。

1. **原材料**: 名称・単位・標準単価を登録し、仕入（数量・単価）と棚卸調整（増減）を記録します。在庫は**移動平均法**で評価し、同じ日は受入を払出より先に処理します。在庫を超えて払い出すと「在庫不足」を表示します。仕入代金の支払いは仕訳（原材料／買掛金など）で記録します。
2. **設備**: 取得日・取得価額・残存価額・耐用年数・年間稼働時間・1時間の運転費を登録します。**時間当たり費用** ＝（取得価額−残存価額）÷耐用年数÷年間稼働時間＋運転費。減価償却は定額法・月割（取得月を含む）で年度ごとの予定を表示し、「仕訳を計上」で減価償却費／減価償却累計額を計上します。
3. **製品**: 1単位あたりの原材料の使用量とロス率（総使用量＝使用量÷(1−ロス率)）、設備の稼働時間、作業時間と賃率、製造間接費の配賦率を登録すると、**標準原価**を内訳つきで表示します。原材料の標準単価が0のときは基準日の移動平均単価を使います。
4. **製造実績**: 製造日と数量を記録します。実際の消費量・稼働時間・作業時間を入れればその値、空欄なら標準×数量を使います。材料は製造日時点の移動平均単価で払い出し、**実際原価・単位原価・標準原価との差異**（材料・設備・労務）を表示します。

材料費を帳簿に反映するには、製造で消費した原材料の金額を「材料費／原材料」の仕訳で振り替えます（デモでは毎月振り替えています）。

## 統計・予測

- **統計**: 期間の月別収入・支出・収支・貯蓄率（収支÷収入）と、科目別の合計・構成比・月平均・中央値・標準偏差・最小・最大・変動係数（標準偏差÷平均）・発生月数を表示します。変動係数が大きい科目は月ごとのばらつきが大きい科目です。
- **支出予想**: 基準日の月は途中なので、翌月から最大36か月を予測します。科目ごとに、履歴（最大120か月、最初の記帳より前は含めません）から次の方法で予測します。
  - 移動平均（直近6か月の平均）
  - 線形トレンド（最小二乗法の直線）
  - 季節変動（13か月以上の履歴で、前年同月×直近12か月の水準比）
  - 自動選択では、直近最大6か月を1か月先ずつ予測した平均絶対誤差が最小の方法を選びます。
- **予定の加算**: 未計上の計画（費用・収益の科目）と債権債務の返済予定の利息を「予定」として加えます。計画や回収・返済から計上した過去の仕訳は統計の履歴から除くので、定期取引は二重に数えません。定期取引を計画から計上せず手入力している場合は、計画と履歴の両方に現れるため、計画から計上する運用をおすすめします。
- **予測の幅**: 検証誤差の二乗平均平方根×1.96を上下の幅（約95%）として表示します。
- **予定の返済・振替**: ローン元本の返済や積立のように費用ではない予定の支払いを月別に別欄で表示します。

## 帳票

損益計算書・貸借対照表・試算表・総勘定元帳を、期間または基準日で表示します。貸借対照表は、まだ純資産に振り替えていない損益の累計を「損益の累計（未振替）」として含め、貸借の一致を確認します。「仕訳CSVを出力」はUTF-8（BOM付き）・CRLFのCSVで、表計算ソフトや他の会計ソフトへの取り込みに使えます。「SQLiteバックアップ」は一貫したコピーをダウンロードします。

## 変更履歴

すべての変更は版番号・日時・操作者とともに記録されます。別の人やAIが先に変更した後に保存すると、上書きせずに「再読み込みしてからやり直してください」と表示します。

## AIから使う（MCP）

`yyaccountant --mcp books.sqlite3` をMCPクライアントに登録します（[設定例](../../help/help.md)）。AIも画面と同じ検証・競合検出・監査を通ります。金額は文字列で渡します。`--read-only` を付けると読み取りだけになります。
