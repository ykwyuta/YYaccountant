# 勘定科目の選び方

<!-- core/src/chart.rs から生成。直接編集せず `YYA_UPDATE_DOCS=1 cargo test -p yy-accountant --test docs` で更新します。 -->

帳簿を作ると、種類に応じた次の科目表が登録されます。どの科目にも使い分けの説明があり、アプリの「かんたん入力」「勘定科目・取引先 › 使い分けガイド」やMCPの `account_guide` で、内容の言葉（例: ガソリン、住民税）から候補を探せます。説明は一般的な記帳の考え方で、税額や特例の判断は最新の制度と専門家の助言で確認してください。

## 家計の帳簿

### 迷いやすい科目の使い分け

#### 食費・外食費・交際費

誰のために、どこで食べたかで分けます。自宅で食べる物は食費、自分や家族の外食は外食費、他人との付き合いやもてなしは交際費です。

| 例 | 選ぶ科目 |
|---|---|
| スーパーで夕食の材料 | 501 食費 |
| コンビニ弁当を持ち帰り | 501 食費 |
| 家族でファミレス | 502 外食費 |
| 同僚と飲み会（割り勘の自分の分） | 611 交際費 |
| 友人宅への手土産 | 611 交際費 |

#### 日用品・特別支出・衣服美容

使い切る生活用品は日用品、1回1万円以上で1年以上使う家具・家電は特別支出、身に着ける物と美容は衣服・美容です。

| 例 | 選ぶ科目 |
|---|---|
| 洗剤とティッシュ | 511 日用品 |
| 掃除機を3万円で購入 | 641 特別支出 |
| 冬物コート | 601 衣服・美容 |
| 美容院 | 601 衣服・美容 |

#### クレジットカードの購入と引落し

支出はカードで買った日に1回だけ記録し、引落し日は「クレジットカード／普通預金」の振替にします。引落し額を支出にすると購入時と合わせて二重計上になります。

| 例 | 選ぶ科目 |
|---|---|
| カードで食材を購入 → 食費／クレジットカード | 201 クレジットカード |
| 翌月の引落し → クレジットカード／普通預金 | 111 普通預金 |

#### ローン返済の元金と利息

返済額は元金（ローン残高の減少）と利息（支払利息）に分けます。債権債務画面で返済予定を登録すると内訳を計算できます。家賃は住居費です。

| 例 | 選ぶ科目 |
|---|---|
| 住宅ローン返済の元金部分 | 211 ローン・借入金 |
| 住宅ローン返済の利息部分 | 661 支払利息 |
| 賃貸の家賃 | 521 住居費 |

#### 保険料と保険積立金

解約返戻金がない掛け捨て部分は保険料、返戻金のある積立部分は資産の保険積立金、自動車保険は自動車関連費です。

| 例 | 選ぶ科目 |
|---|---|
| 医療保険（掛け捨て） | 571 保険料 |
| 学資保険 | 132 保険積立金 |
| 任意の自動車保険 | 552 自動車関連費 |

#### 交通費と自動車関連費

公共交通機関は交通費、自分の車を使うための費用は自動車関連費です。

| 例 | 選ぶ科目 |
|---|---|
| 通勤定期 | 551 交通費 |
| タクシー | 551 交通費 |
| ガソリン | 552 自動車関連費 |
| 車検 | 552 自動車関連費 |

#### 振替（支出でも収入でもない移動）

自分の口座・財布・電子マネー・投資の間の移動は振替です。支出にすると家計の支出が過大になります。

| 例 | 選ぶ科目 |
|---|---|
| ATMで現金を引き出す | 101 現金 |
| 定期預金へ積立 | 112 定期預金・貯蓄 |
| Suicaに口座からチャージ | 121 電子マネー・プリペイド |
| 投資信託を購入 | 131 投資・証券口座 |

#### 貸付金・立替金・交際費

返してもらう約束があるなら貸付金、近日中に精算される一時的な支払いは立替金、返してもらわないお金は交際費などの支出です。

| 例 | 選ぶ科目 |
|---|---|
| 友人に1万円貸す | 141 貸付金 |
| 飲み会の会計を立て替え | 142 立替金 |
| 甥へのお年玉 | 611 交際費 |

## 個人事業主の帳簿

### 迷いやすい科目の使い分け

#### 事業主貸と事業主借

お金の流れの向きで分けます。事業→私的は事業主貸、私的→事業は事業主借です。経費にならない税金・保険料を事業用口座から払ったときも事業主貸です。

| 例 | 選ぶ科目 |
|---|---|
| 事業用口座から生活費を引き出す | 191 事業主貸 |
| 事業用口座から住民税を納付 | 191 事業主貸 |
| 個人のカードで事業の文房具を購入 | 311 事業主借 |
| 事業用口座の預金利息 | 311 事業主借 |

#### 消耗品費と工具器具備品（固定資産）

取得価額10万円未満または使用期間1年未満は消耗品費。10万円以上は固定資産に計上し減価償却します（一括償却資産・少額減価償却資産の特例あり。上限・期限は最新の税制を確認）。

| 例 | 選ぶ科目 |
|---|---|
| マウスとキーボード 8,000円 | 520 消耗品費 |
| ノートパソコン 25万円 | 164 工具器具備品 |
| コピー用紙 | 520 消耗品費 |

#### 修繕費と資本的支出

元の状態に戻す・維持するなら修繕費、性能向上・耐用年数の延長なら資本的支出として資産に加算します。20万円未満、または3年以内の周期の修理は修繕費にできます。

| 例 | 選ぶ科目 |
|---|---|
| 故障したエアコンの修理 | 519 修繕費 |
| 店舗の全面改装で機能向上 | 161 建物・付属設備 |

#### 接待交際費・会議費・福利厚生費

相手と目的で分けます。取引先をもてなすなら接待交際費、打合せのための茶菓・簡単な飲食なら会議費、従業員全員のためなら福利厚生費。事業主一人の飲食は経費になりません。

| 例 | 選ぶ科目 |
|---|---|
| 取引先との会食 | 517 接待交際費 |
| 打合せ中のコーヒー代 | 530 会議費 |
| 従業員の忘年会 | 522 福利厚生費 |
| 取引先へのお歳暮 | 517 接待交際費 |

#### 旅費交通費・車両費・地代家賃

公共交通機関と出張費用は旅費交通費、自社車両の維持費は車両費、月極の駐車場は地代家賃です。

| 例 | 選ぶ科目 |
|---|---|
| 取引先訪問の電車代 | 514 旅費交通費 |
| 出張先のホテル | 514 旅費交通費 |
| 社用車のガソリン | 529 車両費 |
| 事務所の月極駐車場 | 526 地代家賃 |
| 訪問先近くのコインパーキング | 514 旅費交通費 |

#### 通信費・支払手数料・荷造運賃

通話・回線・書類郵送は通信費、振込・決済・仲介の手数料は支払手数料、商品の発送は荷造運賃です。

| 例 | 選ぶ科目 |
|---|---|
| スマホ料金 | 515 通信費 |
| 振込手数料 | 528 支払手数料 |
| ネットショップの販売手数料 | 528 支払手数料 |
| 商品の宅配便 | 512 荷造運賃 |
| 請求書の郵送 | 515 通信費 |

#### 外注工賃と給料賃金

業務委託・請負（成果物に対する支払い、指揮命令なし）は外注工賃、雇用契約（時間・場所の拘束、指揮命令あり）は給料賃金です。

| 例 | 選ぶ科目 |
|---|---|
| デザインを外部に委託 | 524 外注工賃 |
| アルバイトの時給 | 523 給料賃金 |

#### 租税公課と事業主貸（経費にならない税）

事業税・事業用の固定資産税・自動車税・印紙税は租税公課。所得税・住民税・国民健康保険・国民年金は経費にならないため事業主貸です。

| 例 | 選ぶ科目 |
|---|---|
| 収入印紙 | 511 租税公課 |
| 個人事業税 | 511 租税公課 |
| 所得税の納付 | 191 事業主貸 |
| 国民年金 | 191 事業主貸 |

#### 売掛金と未収入金

本業の売上の未回収は売掛金、本業以外（資産売却・保険金など）の未回収は未収入金です。

| 例 | 選ぶ科目 |
|---|---|
| 請求書を発行した制作代金 | 121 売掛金 |
| 中古の車両を売却した代金 | 122 未収入金 |

#### 買掛金・未払金・未払費用

商品・材料の仕入れの後払いは買掛金、それ以外の購入の後払い（カード払い含む）は未払金、継続サービスの経過分で支払日未到来のもの（決算整理）は未払費用です。

| 例 | 選ぶ科目 |
|---|---|
| 材料を掛けで仕入れ | 201 買掛金 |
| 事業用カードで備品を購入 | 202 未払金 |
| 当月分の借入利息が翌月払い | 203 未払費用 |

#### 前払金と前払費用

物の購入代金の手付は前払金、家賃・保険料など継続サービスの未経過分は前払費用です。

| 例 | 選ぶ科目 |
|---|---|
| 機械購入の手付金 | 141 前払金 |
| 来期分の事務所家賃を前払い | 142 前払費用 |

#### 前受金・預り金・仮受金

サービス提供前の代金受取は前受金、他者に代わって預かる税金等は預り金、内容不明の入金は仮受金です。

| 例 | 選ぶ科目 |
|---|---|
| 講座の受講料を事前受領 | 211 前受金 |
| 給与から源泉所得税を天引き | 212 預り金 |
| 誰からかわからない振込 | 213 仮受金 |

#### 仮払金と立替金

自分の事業の概算払いで後で精算するものは仮払金、他人が負担すべき費用を一時的に払ったものは立替金です。

| 例 | 選ぶ科目 |
|---|---|
| 出張前に旅費を概算で渡す | 143 仮払金 |
| 取引先の送料を立て替える | 144 立替金 |

#### 仕入高・原材料・消耗品費

そのまま売る物は仕入高、製造に使う材料は原材料（使った分が材料費）、事業で使うだけの物は消耗品費です。

| 例 | 選ぶ科目 |
|---|---|
| 転売用の雑貨 | 501 仕入高 |
| 製品用の布地 | 132 原材料 |
| 梱包用テープ（発送用は荷造運賃でも可） | 520 消耗品費 |

#### 借入金の返済（元金と利息）

元金部分は借入金の減少で経費になりません。利息部分だけが利子割引料（経費）です。

| 例 | 選ぶ科目 |
|---|---|
| 融資の毎月返済の元金 | 221 借入金 |
| 同じ返済の利息 | 525 利子割引料 |

#### 家事按分

自宅兼事務所の家賃・光熱費・通信費は、面積・使用時間など合理的な割合で事業分だけを経費にし、残りは事業主貸にします。簡易入力の「事業割合」を使うと自動で分けられます。

| 例 | 選ぶ科目 |
|---|---|
| 家賃10万円・事業割合30% → 地代家賃3万円 | 526 地代家賃 |
| 同 → 残り7万円 | 191 事業主貸 |

#### 売上高と雑収入

本業の収入は売上高、本業以外の事業関連収入は雑収入、預金利息は事業主借です。

| 例 | 選ぶ科目 |
|---|---|
| 制作報酬 | 401 売上高 |
| 作業くずの売却 | 411 雑収入 |
| 事業用口座の利息 | 311 事業主借 |
